# git-practice

极客神经元社团暨人工智能实验室 · 基础考核第 1 项练习仓库

## 用途

这是一个本地 Git 练习项目，用于熟悉 Git 的日常操作：
提交（commit）、查看历史（log）、回退（reset）、分支（branch）。

## 常用命令

| 命令 | 作用 |
| --- | --- |
| `git status` | 查看当前改动 |
| `git add .` | 把所有改动加入暂存区 |
| `git commit -m "说明"` | 提交一次快照 |
| `git log --oneline` | 查看提交历史 |
| `git diff` | 查看未暂存的改动 |
